# nightmare-druaga-recomp

Static recompilation of The Nightmare of Druaga: Fushigi no Dungeon (PS2, USA, SLUS-210.71) to native Windows and Linux (Steam Deck / SteamOS).

Early days. No game data in this repo - you need your own disc image.

- `tools/datachain.py` - extract DATA.DAT (decrypts the file table using the key from your own SLUS_210.71)
- `docs/NOTES.md` - reverse-engineering notes

Built on [PS2Recomp](https://github.com/ran-j/PS2Recomp).
